How it works

A tiny app on the PC waits quietly in the tray. You start every connection from the Chromebook.

🤝

Handshake

The Chromebook and your PC find each other through a private, encrypted room. This takes a few seconds and carries no screen data.

⚡

Direct stream

Video goes straight between the two computers with WebRTC, encoded by your graphics card at up to 60 fps. On strict school networks, an optional Cloudflare relay takes over.

🖱️

Real control

Mouse, keyboard, scroll, clipboard and special keys. Desktop mode keeps text sharp; Game mode captures the mouse for smooth camera movement.

Set it up, step by step

About 10 minutes, only once. You need three things: your Windows PC, your Chromebook and your phone. Not sure about a step? Click ▶ show me next to it to watch it.

PART 1 · ON YOUR WINDOWS PC
  1. Download. On the PC (not the Chromebook), click Download for Windows. A file called RemoteLink.zip lands in your Downloads folder. ▶ show me
  2. Unzip it. A .zip is a packed folder, so unpack it first: open File Explorer (the yellow folder on the taskbar) → Downloads → right-click RemoteLink.zip → Extract All… → change the folder to Documents → Extract. ▶ show me
  3. Install. In the new RemoteLink folder, double-click host, then double-click install (the one with the gear icon). If a blue box says “Windows protected your PC”, click More info → Run anyway. A black window downloads about 110 MB; let it finish on its own. ▶ show me
  4. Password & phone. The settings window opens. Name your PC, pick a password (10+ characters) and type it twice. Scan the square code with an authenticator app on your phone, type the 6 digits it shows, click Check, then Save. ▶ show me
  5. Leave the pairing code on screen. You'll type it on the Chromebook next.
PART 2 · ON THE CHROMEBOOK
  1. Open the app. Go to this page and click Open RemoteLink, then press Ctrl+D to bookmark it. ▶ show me
  2. Pair. Type the pairing code from your PC and click Pair. You only do this once.
  3. Log in. Type your password and the 6-digit code from your phone, tick Remember this Chromebook, then click Connect. ▶ show me
  4. Next time it's just your password and Enter.

Stuck while installing?
  • There's no “Extract All…”. On Windows 11, click Show more options at the bottom of the menu first. Still missing? Another program has taken over .zip files: right-click → Open with → Windows Explorer, then click Extract all at the top of the window.
  • I can't see “install.bat”. Windows hides the end of file names. Pick the file called install whose type is Windows Batch File (gear icon).
  • A blue box says “Windows protected your PC”. Click More info, then Run anyway. It shows up because RemoteLink is new and isn't signed by a big company.
  • The black window says Node.js was installed. Close it and double-click install again.
  • The black window says “Install failed” or closes at once. Check the PC's internet connection and double-click install again.
  • Where did RemoteLink go? It lives next to the clock (click the ^ arrow if you don't see its icon) and starts by itself with Windows. Right-click it → Settings & pairing to see your pairing code again.
On the PC, set Windows to never ask to sign in again after being away (Settings → Accounts → Sign-in options), and don't lock it with Win+L before you leave. Windows doesn't allow the lock screen to be controlled remotely.

Built to be safe

Your PC is never exposed to the internet: no open ports, and nobody gets in without your password.

  • Your password never travels, only a one-time proof of it.
  • Authenticator code on the first login from every new device.
  • Trusted Chromebooks can be removed at any time from the PC.
  • Everything is encrypted: the handshake with AES-256, the stream by WebRTC.
  • Lockout after 5 wrong tries (15 minutes, then longer).
  • Panic key on the PC: Ctrl+Alt+Shift+K ends the session and blocks new logins.
  • View-only mode, enforced by the PC itself.
  • Alerts on every login, failed attempt and lockout, plus an activity log.
School Chromebooks are usually monitored, so whatever you open on your PC can be visible to the school. Use a strong password, and check your school's rules about remote access.

Help

“Your PC didn't answer”

The PC must be on, awake and online, with the RemoteLink tray icon cyan (it may be hidden under the ^ arrow next to the clock).

“The stream didn't start”

The network blocks direct video connections. Add the free Cloudflare relay in the PC settings (tray → Settings & pairing → Settings).

Black screen

The PC is on the lock screen or showing an administrator (UAC) prompt. Windows doesn't allow either to be controlled remotely.

It feels laggy

Open stats with Ctrl+Alt+Shift+S. “Relay” adds a little delay; lower the bandwidth to Balanced or use 30 fps on weak Wi-Fi. A network cable on the PC helps.

Keyboard shortcuts in the app

Hold Ctrl+Alt+Shift and press F full screen · G game mode · S stats · H toolbar · T type text · M sound · C second cursor · Q disconnect. The Search key works as the Windows key.
