The same RemoteLink, for Linux. Your PC streams its screen and sound to any Chromebook browser and takes your mouse and keyboard back, with low latency, from anywhere. The Chromebook part is identical to the Windows version.

1. Install the system libraries it needs (once):

sudo pacman -S --needed libxtst nss gtk3 alsa-lib

2. Install RemoteLink (no sudo):

curl -fsSL https://scipiotoni.github.io/Remotelink/RemoteLink-linux.tar.gz | tar -xz -C ~ && bash ~/RemoteLink/install.sh

x86_64 or ARM64 · an X11 session (see below) · installs into ~/RemoteLink · downloads about 160 MB once

First: an X11 session

RemoteLink sees and controls the screen through X11. Wayland doesn't let an app do that without asking at the PC every time, so it isn't supported yet.

✅

Works

KDE Plasma (X11), XFCE, Cinnamon, MATE, LXQt, i3 and other X11 window managers.

🔁

KDE Plasma

Plasma starts in Wayland by default. Install the X11 session with sudo pacman -S plasma-x11-session, log out, and pick Plasma (X11) at the login screen.

⛔

Not yet

GNOME (Wayland-only now) and other Wayland sessions such as Hyprland or Sway: the Chromebook would see a black screen.

Not sure which one you're in? Run echo $XDG_SESSION_TYPE in a terminal: it must say x11.

Set it up, step by step

About 10 minutes, only once. You need your Linux PC, your Chromebook and your phone.

PART 1 · ON YOUR LINUX PC
  1. Open a terminal and run the two lines from the top of this page (the first asks for your password; the second doesn't).
  2. Wait for the download. It ends by opening the RemoteLink settings window.
  3. Password & phone. Name your PC, pick a password (10+ characters) and type it twice. Scan the square code with an authenticator app on your phone, type the 6 digits, click Check, then Save.
  4. Leave the pairing code on screen. You'll type it on the Chromebook next. Later you'll find it in the tray icon → Settings & pairing, or with bash ~/RemoteLink/settings.sh.
PART 2 · ON THE CHROMEBOOK
  1. Open the app. Go to the RemoteLink app and bookmark it with Ctrl+D.
  2. Pair. Type the pairing code from your PC and click Pair.
  3. Log in. Your password and the 6-digit code from your phone, tick Remember this Chromebook, Connect.
  4. Next time it's just your password and Enter.

The app, its toolbar and shortcuts work exactly as on Windows: see the walkthrough. The Search key works as the Super key.

Turn off automatic screen locking on the PC (your desktop's Screen Locking / Power settings). The lock screen can't be controlled remotely. RemoteLink keeps the PC awake while it runs.

Linux specifics

Everything else works like the Windows version.

🔊

Sound just works

With PipeWire (pipewire-pulse) or PulseAudio, RemoteLink streams whatever your speakers play, using the “Monitor of …” source. Nothing to set up.

🚀

Starts by itself

An autostart entry in ~/.config/autostart starts it when you log in (KDE, XFCE, Cinnamon, MATE, LXQt). On i3, add exec bash ~/RemoteLink/start.sh to your config.

🧭

Tray icon

RemoteLink sits in the system tray. No tray on your desktop? Everything is still reachable with bash ~/RemoteLink/settings.sh.

Help

The Chromebook shows a black screen

You're most likely in a Wayland session. Run echo $XDG_SESSION_TYPE: if it says wayland, log out and choose an X11 session at the login screen (see above).

I can see the PC but the mouse and keyboard do nothing

Install libxtst (sudo pacman -S libxtst) and make sure you're in an X11 session, then restart RemoteLink: tray → Quit RemoteLink, then bash ~/RemoteLink/start.sh. The activity log (tray → Activity log) says what's missing.

No sound

Check that pactl list short sources shows a .monitor source (install pipewire-pulse if the command is missing), then reconnect from the Chromebook.

RemoteLink doesn't start (sandbox error)

Some hardened kernels forbid what Chromium's sandbox needs. start.sh detects this and starts without the sandbox. If it still fails, run bash ~/RemoteLink/start.sh from a terminal and look at the activity log in ~/.config/RemoteLink/activity.log.

Other distributions

It also works on Debian, Ubuntu, Fedora and others with an X11 session. Install the same libraries with your package manager (for example sudo apt install libxtst6 libnss3 libgtk-3-0 libasound2), then run the install line.

Update or uninstall

Update: run the install line again; your settings are kept. Uninstall: tray → untick Start when I log in → Quit RemoteLink, then delete ~/RemoteLink. Settings live in ~/.config/RemoteLink.
