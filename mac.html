Your Mac,
on your Chromebook.

The same RemoteLink, for macOS. The Mac streams its screen to any Chromebook browser and takes your mouse and keyboard back, with low latency, from anywhere. The Chromebook part is identical to the Windows version.

Install: open Terminal on the Mac, paste this line, press Return.

curl -fsSL https://scipiotoni.github.io/Remotelink/RemoteLink-mac.tar.gz | tar -xz -C ~ && bash ~/RemoteLink/install.sh

macOS 12 or newer · Apple silicon or Intel · installs into your home folder (~/RemoteLink), no admin password · downloads about 160 MB once

Set it up, step by step

About 10 minutes, only once. You need your Mac, your Chromebook and your phone.

PART 1 · ON YOUR MAC
  1. Open Terminal. Press ⌘+Space, type Terminal, press Return.
  2. Paste the install line from the top of this page and press Return. Let it download; it finishes by opening the RemoteLink settings window.
  3. Password & phone. Name your Mac, pick a password (10+ characters) and type it twice. Scan the square code with an authenticator app on your phone, type the 6 digits, click Check, then Save.
  4. Allow two permissions. macOS asks for Screen Recording and Accessibility for an app called Electron (that's RemoteLink's engine). In System Settings → Privacy & Security, turn Electron on in both lists. The RemoteLink icon in the menu bar has shortcuts to both.
  5. Restart RemoteLink once so the permissions apply: menu-bar icon → Quit RemoteLink, then in Terminal: bash ~/RemoteLink/start.sh
PART 2 · ON THE CHROMEBOOK
  1. Open the app. Go to the RemoteLink app and bookmark it with Ctrl+D.
  2. Pair. Type the pairing code shown on the Mac (menu-bar icon → Settings & pairing) and click Pair.
  3. Log in. Your password and the 6-digit code from your phone, tick Remember this Chromebook, Connect.
  4. Next time it's just your password and Enter.

The app, its toolbar and shortcuts work exactly as on Windows: see the walkthrough.

Set the Mac so it doesn't lock itself: System Settings → Lock Screen → Require password after screen saver or display is turned off → a long time or Never. macOS doesn't allow the lock screen to be controlled remotely. RemoteLink keeps the Mac awake while it runs.

Mac specifics

Everything else works like the Windows version.

⌨️

Ctrl works as ⌘

Your Chromebook has no ⌘ key, so Ctrl acts as ⌘: Ctrl+C, Ctrl+V, Ctrl+Z do what you expect, and the Search key becomes Control. Turn it off in the menu-bar menu if you'd rather have real Control.

🔊

Sound needs BlackHole

macOS can't share its sound by itself. Install the free BlackHole 2ch audio driver (see Help below) and RemoteLink picks it up automatically. Without it you get picture and control, no sound.

🚀

Starts by itself

RemoteLink starts when you log in to the Mac (menu-bar menu → Start when I log in). It lives in the menu bar at the top right, not in the Dock.

Help

The Chromebook shows a black or empty screen

Screen Recording isn't allowed yet. System Settings → Privacy & Security → Screen & System Audio Recording → turn on Electron, then quit RemoteLink from the menu bar and run bash ~/RemoteLink/start.sh.

I can see the Mac but the mouse and keyboard do nothing

Accessibility isn't allowed yet. System Settings → Privacy & Security → Accessibility → turn on Electron, then quit and start RemoteLink again.

How do I get the Mac's sound?
  1. Install BlackHole 2ch (free, from Existential Audio's website, or brew install blackhole-2ch).
  2. Open Audio MIDI Setup (⌘+Space → “Audio MIDI Setup”) → + at the bottom left → Create Multi-Output Device → tick your speakers and BlackHole 2ch.
  3. System Settings → Sound → Output → choose the Multi-Output Device.
  4. Reconnect from the Chromebook. The first time, macOS asks whether Electron may use the microphone: allow it (that's how it hears BlackHole).
Where's the settings window / pairing code?

Click the RemoteLink icon in the menu bar → Settings & pairing. No icon? Start it with bash ~/RemoteLink/start.sh.

Update or uninstall

Update: run the install line again; your settings are kept. Uninstall: menu-bar menu → untick Start when I log in → Quit RemoteLink, then delete the RemoteLink folder in your home folder. Settings live in ~/Library/Application Support/RemoteLink.
