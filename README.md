# RemoteLink

Control your Windows PC from a Chromebook browser: low latency, from anywhere, with nothing installed on the Chromebook.

**Website:** https://scipiotoni.github.io/Remotelink/
- `index.html`: landing page (what it is, setup, security, help)
- `app.html`: the Chromebook app (single self-contained HTML file)
- `RemoteLink.zip`: the Windows PC app (run `host\install.bat`)

Each person installs the PC app on their own PC and gets their own password, authenticator code and pairing code.
